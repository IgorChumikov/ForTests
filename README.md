# ForTests

## Русский

ForTests — учебный iOS-проект и личная песочница для изучения SwiftUI. Здесь можно быстро проверять новые API, создавать прототипы экранов и экспериментировать с поведением интерфейса.

В проекте собраны:

- примеры Liquid Glass для iOS 26;
- графики, анимации и переходы;
- кастомные Tab Bar, Bottom Sheet и другие UI-компоненты;
- демонстрационные экраны погоды и учёта расходов;
- переиспользуемые SwiftUI-модификаторы и расширения.

Проект не является готовым продуктом: отдельные экраны и компоненты используются для обучения, тестов и быстрой проверки идей.

## English

ForTests is an educational iOS project and a personal playground for learning SwiftUI. It provides a convenient place to explore new APIs, prototype screens, and experiment with interface behavior.

The project includes:

- Liquid Glass examples for iOS 26;
- charts, animations, and transitions;
- custom tab bars, bottom sheets, and other UI components;
- sample weather and expense-tracking screens;
- reusable SwiftUI modifiers and extensions.

This is not a production application. Its screens and components are created for learning, testing, and quickly validating UI ideas.
